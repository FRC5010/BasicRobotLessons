{%- comment -%} Just the Docs puts this file in every page's . It carries two things. First, the dark color scheme. The theme loads its light stylesheet; this adds the dark one on top, and the dark one wins wherever they differ. They differ only in colors, and every light rule has a dark twin, so light plus dark looks exactly like dark alone. The `media` attribute decides whether the dark sheet applies: the system's setting at first, so a reader whose computer is set to dark gets dark with no script at all, and "screen" or "not all" once they pick one with the button in header_custom.html. Only ever on screen: a printed lesson is always light, or its light gray text would be all but invisible on paper. The theme's own jtd.setTheme swaps the light stylesheet out for the dark one instead. That leaves the page with no styles until the new one downloads, and the theme's script picks that moment to scroll the sidebar to the current lesson: with no styles the sidebar isn't scrollable, so the whole page scrolled down instead. Second, the sidebar's "under construction" pills, which _plugins/lesson_status.rb writes for the OpMode track's lessons that aren't up to date yet. The pills match links by their href, and the theme's script removes the href from the link to the page you're on, so that link gets its own rule, from the page's status. {%- endcomment -%} {%- if site.data.lesson_status_css and site.data.lesson_status_css != "" %} {%- endif %}
