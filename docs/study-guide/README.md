# Concepts Study Guide

The lessons teach one step at a time, in the order you build the robot. This
guide goes the other way: one page per idea, gathering what the lessons say
about it in one place. Use it to study before a quiz, to look something up
mid-build, or to see how an idea you met early on turns out by the end of the
course.

There's nothing to type here. Each page explains an idea, shows it in the
course's own code, and links to the lesson that teaches it in depth. You don't
need to have done every lesson: when a page leans on something from later in
the course, it says so ("from Lesson 24 on") and explains enough to follow.

## Check yourself
