# Java

The Java ideas the course uses, from classes and objects to lambdas, suppliers and annotations.

- [Classes, enums and objects](01-classes-enums-objects.md): blueprints and the things built from them, fields, constructors, `static`, enums and records.
- [Methods, variables and types](02-methods-variables-types.md): types, methods, locals, decisions, loops, `Optional`, and numbers that know their unit.
- [Inheritance and interfaces](03-inheritance-interfaces.md): `extends`, interfaces and default methods, `super` and `protected`, and has-a against is-a.
- [Lambdas and coroutines](04-lambdas-coroutines.md): code as a value, method references, and command bodies that pause.

More pages in this group are being written.
